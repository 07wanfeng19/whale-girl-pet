### v1.1 交互扩展的实现方式（重要，别再走弯路）

`VideoGlView` 是 **GLSurfaceView**，View 的 `setRotation/setTranslation/setAlpha` 对它**全部无效**
（Surface 是独立图层，不吃 View 变换）。所以侧倾和视线都做在**顶点着色器**里：

```
uniform uRot     侧倾角（弧度）
uniform uPivot   旋转中心（clip 空间，= 可见裁切区中心）
uniform uAspect  视频宽高比，先把 clip 空间换成等比空间再转，否则会被拉斜
uniform uOff     视线偏移（clip 空间）
```
当前值在 GL 线程逐帧向目标值逼近（`leanCur += (target-cur)*0.35`），这就是原版的 lerp 手感。
旋转中心随裁切窗口变化而更新（`PetService.updateMetrics()`），否则侧倾会绕错点。

**随机眨眼当前版做不了**：眨眼需要眼部图层动画，webm 视频路线没有单帧控制能力。
计划中的 Live2D 实时渲染版（另开一版，见决策 #2）天然支持眨眼，留到那一版做。

## 八、v1.2 流畅度优化（2026-10-19）

### 实测瓶颈（先量后改，别猜）

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 静止渲染帧率 | 24fps | 24fps（不变，够用） |
| **拖拽时渲染帧率** | **24fps** | **121fps**（达屏幕刷新率） |
| 拖拽时 CPU | 11% | 14%（可接受） |
| 单帧耗时峰值 | 6-11ms 尖峰 | 全程 <2.5ms |
| 主线程慢帧 | 16 次 / 62 帧 | 0 次（主线程不再参与渲染） |
| 悬浮窗数量 | 每次弹出都增删 | 固定 2 个，只切可见性 |

### 三项改动

1. **动画期间切连续渲染**（`VideoGlView.onDrawFrame`）
   `RENDERMODE_WHEN_DIRTY` → 侧倾/视线插值只能在 24fps 视频帧到达时更新，
   而拖拽时窗口位置按触摸事件更新（120Hz）。两者不同步 = 拖拽顿挫。
   现在动画中切 `RENDERMODE_CONTINUOUSLY`，静止立刻退回按需渲染（省电）。

2. **表情包解码移出主线程**
   原来每 10 秒弹表情包时，PNG 解码 + `createScaledBitmap` 全在主线程做，
   造成 16 次慢主线程。现在后台解码并缓存缩放结果（`showMemeAsync`）。

3. **悬浮窗复用**
   气泡窗/配图窗原来每次 `addView`/`removeView`，现在只切 `setVisibility`。

### 试过但放弃的方案（别再试）

- **补帧到 30fps**（`minterpolate` 光流 / `fps` 重采样）：实拍对比画质明显劣化
  （边缘重影、线条发虚），体积涨 2.5 倍。画质优先，放弃。
- **缩小渲染 Surface**（1040×585 → 860×484）：会裁掉角色底部，
  `CROP_Y + WIN_H > VIDEO_H`，不可行。
- **素材全关键帧重编码**：体积从 431KB 涨到 3.9MB，收益不抵成本。

## 九、代码地图维护机制（2026-10-19）

### 问题
手写的代码地图会过期，而用户看不懂代码、无法人工核对。

### 解法：地图由脚本生成，过期由脚本检测

| 文件 | 作用 |
|---|---|
| `gen-map.sh` | 从源码直接提取文件行数、常量真值、方法名与行号，生成地图 |
| `check-map.sh` | 只读检查，不修改任何文件。三查：方法是否还在、常量值是否变、行号漂移是否 >30 行 |
| `鲸鱼娘-代码地图.md` | 生成产物。**勿手改**，改了会被下次生成覆盖 |

### 使用
```bash
bash /root/dsh/check-map.sh     # 看有没有 ⚠️，没有就是准的
bash /root/dsh/gen-map.sh       # 有 ⚠️ 就重新生成
```
`build_apk.sh` 打完包会自动跑一次 `gen-map.sh`，所以**用打包脚本出的版本，地图一定是新的**。

### 已验证
- 改常量 `BASE_CROP_X 300→320` 不更新地图 → 报 `⚠️ 常量变了`
- 改完重新生成 → 无告警
- 还原代码 + 重新生成 → 无告警

### 注意
`check-map.sh` 早期版本有副作用（会顺手重新生成地图，把错误值写进去），已修正为纯只读。

### 2026-10-20 · v132–v136（1.32–1.36）—— 无障碍自动发送：交给 DeepSeek App 后自己按发送
