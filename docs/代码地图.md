## 四、人工维护区（脚本不覆盖，改这里要自己负责）

**踩过的坑**：
1. `GLSurfaceView` 吃不到 View 变换，侧倾必须进顶点着色器
2. 旋转中心要跟着裁切走，尺寸变了就得调 `updateMetrics()`
3. `.webm/.png/.ttf/.arsc` 必须 ZIP_STORED，否则 `openFd` 打不开
4. 素材是 24fps，渲染每帧仅 1.5ms——帧率上限由素材决定，不是性能
5. 补帧会毁画质（实测边缘重影），已放弃，别重试
6. 表情包解码别放主线程；窗口别反复 addView（v1.2 已修）
7. 头名是 `x-pet-token`，不是 `X-Token`
8. 启动用 `am start .MainActivity`，`am start-foreground-service` 会被拒

**裁切约束**（改尺寸必须满足）：`CROP_X + WIN_W_PX <= VIDEO_W_PX` 且 `CROP_Y + WIN_H_PX <= VIDEO_H_PX`

**构建**：`bash /root/build/build_apk.sh <版本号>`
